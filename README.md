# MOTIONFLOW — Product Website

Premium product landing page for MOTIONFLOW PRO, an independent motion-design toolkit for Adobe After Effects.

## Files

- \`index.html\` — website entry point
- \`styles.css\` — responsive visual system, 3D mockup and layout
- \`script.js\` — mobile navigation, scroll reveal and hero interaction
- \`assets/\` — favicon and vector showcase artwork
- \`downloads/\` — place the downloadable MOTIONFLOW PRO package here

## Enable the plugin download buttons

Download the MOTIONFLOW PRO 0.8.0 package from the ChatGPT conversation and upload it to the \`downloads/\` folder with this exact name:

\`MOTIONFLOW_PRO_0_8_0_Studio_Complete.zip\`

The website buttons already point to that relative path. The package is not included in this repository yet.

## Publish with GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch \`main\` and folder \`/(root)\`.
4. Save and wait for the Pages deployment to complete.
5. GitHub will show the public URL in the Pages settings.

Keep \`index.html\`, \`styles.css\`, \`script.js\`, \`assets/\`, and \`downloads/\` at the repository root. Do not upload only the original website ZIP.

## Product transparency

MOTIONFLOW PRO 0.8.0 is an unsigned Windows CEP development build targeting After Effects 2025 (25.x). Source/static and mock-host checks were performed, but full in-host After Effects runtime testing is still required.
