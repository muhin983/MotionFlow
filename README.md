# MOTIONFLOW — Product Website

Official product landing page for MOTIONFLOW PRO.

## GitHub Pages

This repository is prepared for GitHub Pages. Keep `index.html`, `styles.css`, `script.js`, `assets/`, and `downloads/` at the repository root.

To publish: open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.

The included plugin archive is an unsigned Windows CEP development build. It has source and mock-host checks; test it inside After Effects before treating it as a verified release.
